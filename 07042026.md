### 1. ZNAKOVÁ - BAJTOVÁ

- Lze na něj koukat jako sekvenční

## 3 KLÍČOVÉ INFORMACE (Linux)

### MAJOR → VELKÉ ČÍSLO
Identifikace ovladače (typ zařízení)

### MINOR → MALÉ ČÍSLO
Identifikace konkrétního zařízení

*Major a Minor lze zjistit přes `ls -l`*

### SLUŽBA + PARAMETRY

Představit si to můžeme tabulkou:
```
Operace:    0         1         2
            (init)    (open)    (write)
────────────────────────────────────
Major 5:    init()    open()    write()
```

Příklad: major=5, minor=10, write

## Multitasking - Moderní Systémy

Moderní systémy hlídají ovladače, aby nedošlo k příliš dlouhým přerušením.

Princip: Procesy se musí nějak střídat a vzdávat se procesoru.

## Terminál - Komplikovanější Příklad

```
VSTUP (INPUT):
  Klávesnice → RAW buffer

ZPRACOVÁNÍ:
  - Korekce (backspace, Ctrl+W apod.)
  - Echo (zobrazení znaků)

VÝSTUP (OUTPUT):
  - Obrazovka / Terminál
```

## SOUBOROVÝ SYSTÉM

Různé formáty (Win má NTFS apod.)
Budeme se bavit hlavně o **UNIXU**

### STRUKTURA FILE SYSTÉMU

```
Otevřený soubor
    ↓
Mount (připojení)
    ↓
Adresářová struktura
    ↓
I-Node (Inode)
    ↓
Vyrovnávací paměti
(Ne kvůli rychlosti, ale aby to vůbec fungovalo!)
    ↓
Logický svazek (Volume)
    ↓
Driver
    ↓
Image - Partition
    ↓
HW - Vnější paměť
```

### STRUKTURA DISKU

```
┌─────────────────┐
│  BOOT SEKTOR    │
├─────────────────┤
│ HEADER SEKTOR   │
├─────────────────┤
│   METADATA      │
├─────────────────┤
```
