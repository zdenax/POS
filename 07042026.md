# OVLADAČ - Instrukce Zařízení

## Dva Typy Zařízení

### 1. Znakové (Character) Zařízení - BAJTOVÁ
- **Příklady:** Klávesnice, terminál
- **Charakteristika:** Sekvenční přístup
- Data se zpracovávají po jednom znaku/bajtu

### 2. Blokové (Block) Zařízení - BLOKOVĚ ORIENTOVANÉ
- **Příklady:** Pevný disk
- **Komunikace:** Přes bloky dat
- **Charakteristika:** Náhodný přístup (random access)
- Lze koukat jako na sekvenční (ale není to nutné)
- **Poznámka:** Čtení a zápis je složitější než u znakových zařízení






## Služby (Operace) Ovladače

### Univerzální Služby (dostupné pro všechna zařízení)
- **INIT** - Inicializace ovladače
- **TERMINATE** - Ukončení ovladače
- **OPEN** - Otevření zařízení
- **CLOSE** - Zavření zařízení
- **READ** - Čtení dat
- **WRITE** - Zápis dat
- **STRATEGY** - Strategie přístupu/optimalizace

### Speciální Služby
- Specifické operace pro jednotlivé typy zařízení 







## Tři Klíčové Informace v Linuxu

Tyto informace určují, jak komunikovat se zařízením:

### 1. MAJOR NUMBER (Hlavní Číslo)
- **Funkce:** Identifikace typu ovladače (typ zařízení)
- **Příklad:** major = 5 znamená terminálové zařízení
- Určuje, KTERÝ ovladač se použije

### 2. MINOR NUMBER (Vedlejší Číslo)
- **Funkce:** Identifikace konkrétního zařízení daného typu
- **Příklad:** minor = 0, 1, 2 = jednotlivé instance
- **Zjištění:** Příkazem `ls -l` vidíme major a minor

### 3. SLUŽBA (Operace) + PARAMETRY
- Určuje, JAkou operaci chceme provést
- **Formát:** (major, minor, služba)
- **Příklad:** major=5, minor=10, write

#### Příklad Tabulky Operací:
```
Operace →    0 (init)  1 (open)   2 (write)
Major 5:     init()    open()     write()
```

**Interpretace:** Pro zařízení major=5 voláme odpovídající operaci





## Moderní Systémy - Multitasking a Přerušení

**Princip:** Moderní OS hlídají, jak dlouho ovladače běží, aby se předešlo příliš dlouhým přerušením.

- Procesy se musí střídat a vzdávat se procesoru
- Každý proces dostane určitý čas na běh
- Umožňuje ostatním procesům běžet také
- Zajišťuje responsivnost systému

## Terminál - Komplexnější Příklad

Terminálové zařízení má složitější zpracování se vstupem a výstupem:

```
┌─────────────────────────────────────┐
│        VSTUP (INPUT - RAW)          │
│    Klávesnice → RAW buffer          │
│    (surové, neupravené znaky)       │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│      ZPRACOVÁNÍ (Processing)        │
│  - Editace řádku (line editing)     │
│  - Korekce (backspace, Ctrl+W)      │
│  - Echo (zobrazení znaků)           │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│     VÝSTUP (OUTPUT - Echo)          │
│    Zobrazení na terminál            │
└─────────────────────────────────────┘
```





## Souborový Systém

### Obecně
- Různé formáty: NTFS (Windows), EXT4 (Linux), APFS (macOS)
- Zaměřujeme se na **UNIX/Linux** souborový systém

### Vrstvená Struktura Souborového Systému

```
┌──────────────────────────────────────┐
│    1. Otevřený Soubor (File Desc.)   │
├──────────────────────────────────────┤
│    2. Mount (připojení souborů)      │
├──────────────────────────────────────┤
│    3. Adresářová Struktura           │
├──────────────────────────────────────┤
│    4. Inode (I-Node)                 │
├──────────────────────────────────────┤
│  5. Vyrovnávací Paměti (Buffers)    │

│     - Nutné pro správné fungování    │

│  6. Logický Svazek (Volume)          │
│     - Řídící software (Driver)       │
├──────────────────────────────────────┤
│  7. Partice (Image na Disku)         │
├──────────────────────────────────────┤
│  8. Hardware (Fyzická Vnější Paměť)  │
└──────────────────────────────────────┘
```






## Fyzická Struktura Disku

### Rozložení Dat na Disku

```
┌──────────────────────────┐
│  BOOT SEKTOR             │  ← Spouštěcí sektor (bootloader)
├──────────────────────────┤
│  HEADER SEKTOR           │  ← Metainformace souborového systému
├──────────────────────────┤
│  METADATA                │  ← Informace o souborech (inoды)
├──────────────────────────┤
│  DATA                    │  ← Samotná data souborů
├──────────────────────────┤
│  METADATA (dodatečná)    │  ← Doplňující metainformace
└──────────────────────────┘
```

### Složky Struktury
- **Boot sektor** - Nutný pro spuštění systému
- **Header sektor** - Informace o FS (velikost, povolená práva apod.)
- **Metadata** - Informace o souborech (velikost, vlastník, práva, čas)
- **Data** - Vlastní obsah souborů
- **Metadata (dodatečná)** - Optimalizační a bezpečnostní údaje
